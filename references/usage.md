# 保存与调用

把压缩包解压后，将整个`clawd-watercolor-animation`目录放到Codex的skills目录（通常为`~/.codex/skills/`）。保留SKILL.md、assets、scripts和references的相对结构；不要只复制一份Markdown。重新打开会话后可用`$clawd-watercolor-animation`指定。

也可以先不安装，直接让助手读取本目录SKILL.md。例：“用这个水彩Skill做一段Clawd海边散步的短片，沿用纸纹和晕染，先做10秒。”

本包的安装/制作不包含上传或公开发布；GitHub仓库由用户提供后另行处理。运行需要Node.js、Chrome/Chromium、FFmpeg；绘画库/字体已附，初始化脚本只复制本地文件。

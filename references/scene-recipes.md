# 可复用场景配方

以下以coastal实例为代码参考，不强制新作品复用其剧情或精确时刻。

| 需求 | 对应源码 | 保持的因果与图层 |
|---|---|---|
| 日落海滨、现代城市 | `journey.js`、`modern-city.js`、`coast-story.js` | 主角走人行道，近景车影在机动车道，高楼分前后层且窗灯零星亮 |
| 无肩带背包、持纸 | `backpack.js`、`continuity.js`、`wish-daydream.js` | 身体与附件共用变换，转身和镜头缩放后仍跟手/背 |
| 云朵回忆 | `coast-story.js`、`wish-daydream.js` | 原生云朵裁切；先在画布缓冲区做遮罩，再合成，出入恢复相机与时间 |
| 一团乱麻 | `tangle-options.js`、`r6-details.js` | 淡灰慢转、锚定头部；回忆里的角色也保持相同表达逻辑 |
| 太阳变清单 | `r6-details.js`、`wish-daydream.js` | 太阳处云朵显现，再在实际手部云朵弹出，不让纸张跨镜头漂移 |
| 夕阳大桥持纸走 | `wish-daydream.js` | 宽景巨大太阳、小角色侧面逆光剪影，仍有可见持纸与迈步 |
| 原速幻想片中片 | `fallen-star-dream.js` | 子场景有自己的时间映射，进出恢复父场景状态。实例38.63–49.63恰11秒，不靠慢放拖长 |
| 快乐团聚花海 | `r6-details.js`、`star-journey.js` | 从地上冒出小云、抽茎、开花逐渐变密。先远景花，再人物，再低于脸的前景花，脚可挡、表情可见 |
| 风带回现实 | `star-journey.js` | 风和叶片遮盖画面时切回现实，星星先离场、人物追出，再进入下一场景 |
| 星树照亮笑脸 | `star-journey.js` | 星星入根→沿干上升→枝头增多→环境与脸渐亮→抬头快乐表情→跟住脸推近→圆形缩小结束 |

coastal目前131朵花/三段海滩回忆/单盏月夜路灯等是该作品的布景量。新片按角色尺寸、镜头尺度和预算调整，避免为了匹配数字把脸遮住。

表现孤独时用单份午餐、空长椅或大留白建立语义，再给眼神/身体反应，不只打“孤独”两个字。漫画训斥符号可用`#@*&¥#!`点明语气，不需要增加真实辱骂内容。

# clawd-watercolor-animation

Cursor / Grok Bot skill：带纸张肌理、颜料晕染和手绘墨线的 Clawd 水彩绘本动画（情绪短片、海滨故事、音乐动画）。

## 快速开始

```sh
python3 scripts/init_project.py --template demo --output my-clip
```

- `demo`：约 11 秒抛星示例
- `coastal`：约 90 秒海滨场景库（无用户原曲）

完整规范见 [SKILL.md](SKILL.md)。画风与表演、工程工作流、引擎 API、场景配方见 `references/`。
